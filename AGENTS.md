# mi-web

Reglas de este proyecto para cualquier agente de código que trabaje aquí.

- Web real del negocio de cursos online de Oscar Ojeda — multipágina: portada, una página por servicio, contacto.
- Los textos van en castellano, hablando de tú.
- Los textos de la web salen de marca.md. Nunca se inventan ni se rellenan con frases genéricas de negocio.
- Sin librerías ni dependencias externas, salvo que decidamos lo contrario.
- Sí se pueden usar imágenes, pero siempre guardadas dentro del proyecto (carpeta `imagenes/`). Nunca enlazadas desde el servidor de otro: el día que la muevan, queda un hueco.
- Las fotos de banco valen como provisional, nunca como pieza definitiva: en cuanto haya fotos reales (de Oscar, del curso, de alumnos), se sustituyen.
- No se toca ningún archivo sin pedir permiso antes: enseña qué vas a cambiar y espera el visto bueno.
